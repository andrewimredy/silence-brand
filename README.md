# AdCrab
an extension to mute video advertisements

![alt text](lasercrab.png)


# About
On an internet dominated by advertisements, AdCrab pinches back! The crab's purpose is to differentiate between sports and advertising video content, and mute the tab when ads come on.
An early version relied on calls to the OpenAI API to do content analysis, but this approach is costly and not portable.
I'm currently (April 2025) gathering training data for a MobileNetV3 model, with the goal of a functional local model for the NBA playoffs.
Thanks for checking it out! 🦀
